Dónde están las funciones en el código

En controller/ArticuloRestController.java y controller/ProveedorRestController.java encontrarás los métodos listar, obtener, crear, actualizar y eliminar, con sus anotaciones HTTP. La lógica y las transacciones están en service/CrudService.java.

Un proveedor con medicamentos asociados no se puede eliminar: la API devuelve 409. Los IDs los indica el usuario al crear. No se permite reutilizar un ID o RUC ya registrado.
